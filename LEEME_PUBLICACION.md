# Viajes con Alquimia: web lista para Cloudflare

Descarga `Viajes_con_Alquimia_Web.zip` de esta rama para usar la opción de carga de archivos estáticos de Cloudflare. El ZIP contiene la web compilada, con `index.html` en la raíz.

El código fuente completo se conserva en la rama `main`. Esta rama contiene solamente el paquete listo para publicar.

Versión de origen: `a1de17a699150807d9f4bc23374b133e22bc6e99`.

Se usó la exportación estática de Vinext sobre la compilación existente, sin modificar el código fuente. Se comprobaron en Chromium el diseño, los cuatro filtros, las recomendaciones, la apertura y cierre de detalles, el menú móvil y la carga de imágenes. No hubo errores de JavaScript ni recursos fallidos.

Las actualizaciones por esta vía requieren generar y subir un ZIP nuevo; esta publicación no depende de la conexión automática entre Cloudflare y GitHub.
